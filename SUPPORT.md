# Support

Welcome to the Matcha-AI-DTU support page. We want to ensure you have the best experience possible while contributing to this project.

## How to Get Help

If you have questions or need assistance, please follow these steps in order:

### 1. Check the Documentation

Most setup and usage questions are already answered in our core documentation:

- [README.md](./README.md) - Project overview and quick start.
- [SETUP.md](./SETUP.md) - Detailed step-by-step installation.
- [GLOSSARY.md](./GLOSSARY.md) - Definitions for project-specific jargon.
- [CONTRIBUTING.md](./docs/CONTRIBUTING.md) - How to submit code and follow standards.

### 2. Search GitHub Discussions

We use [GitHub Discussions](https://github.com/FTS18/Matcha-AI-DTU/discussions) as our primary community forum. Search the **Q&A** or **General** categories to see if your question has been asked before.

### 3. Start a New Discussion

If you can't find an answer, please start a new discussion in the **Q&A** category.

- **Do not** open a GitHub Issue for general "How-to" questions.
- **Do not** contact maintainers directly via email or social media for technical support.

## For GSSoC '26 Participants

If you are a contributor for GirlScript Summer of Code:

- Follow the official GSSoC communication channels for program-wide updates.
- Check the [Roadmap](./ROADMAP.md) to see available tasks.
- If an issue is already assigned to someone else, please do not ask for it unless the assignment has been inactive for more than 4 days.

## Becoming a Mentor

If you are an experienced developer and wish to help as a mentor:

- Ensure you are registered as a mentor on the official GSSoC portal.
- Introduce yourself in the **General** category of our Discussions.
- Help review PRs and answer questions in the Q&A section.
